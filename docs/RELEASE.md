## O que mudou no Windows

- Veja um raio verde no painel e na bandeja quando o dispositivo informar que está carregando.
- O receptor USB do MCHOSE V9 Pro Wireless agora é identificado como headset com microfone.
- Use **Ocultar** para tirar um periférico do painel e **Ocultos → Mostrar** para restaurá-lo. A Bolha salva a escolha separadamente dos ícones que você selecionou para a bandeja.

## Como instalar

**Windows x64.** Se você já usa a Bolha 0.5.9.1, a atualização aparece pelo próprio aplicativo. Para instalar manualmente, baixe `Bolha-Setup-0.5.9.2-x64.exe`. O instalador preserva suas preferências e o aprendizado da mascote. Use `SHA256SUMS.txt` para conferir o download.

**Android.** A versão disponível para Android é a [0.5.9.0](https://github.com/kuky13/bolha/releases/download/v0.5.9.0/Bolha-0.5.9.0-Android.apk).
