# Bolha 0.5.3

- A Bolha olha para a bola enquanto corre, sorri no acerto e reage quando o brinquedo escapa. O último toque da embaixadinha manda a bola para o lado sem disparar uma rebatida extra.
- No Windows, a Bolha volta a ficar por cima dos aplicativos comuns sem tirar o foco. Ela libera o monitor para telas cheias e jogos reconhecidos.
- Com **Brincar de comer o ponteiro** ligado no Windows, a Bolha muito irritada pode perseguir o cursor em movimento, engolir e cuspir. Mover ou clicar devolve o ponteiro na hora. A opção continua desligada por padrão.

No Windows, use **Central da Bolha → App → Verificar atualizações** ou baixe o instalador x64 sem assinatura digital. No Android, instale o APK sobre a versão anterior para preservar os dados.

Projeto aberto sob GPL-3.0-or-later, baseado no [Pestinha](https://github.com/mille-okws/pestinha), de mille-okws e colaboradores. Para rodar pelo código, siga as [instruções de instalação](https://github.com/kuky13/bolha/blob/v0.5.3/README.md#rodar-pelo-código-como-no-pestinha).
